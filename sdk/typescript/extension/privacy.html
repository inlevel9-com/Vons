VONS · RESEARCH PREVIEW 0.1.0

Local by design.

The extension compares candidate choices using a model you import. It cannot read or modify web pages and never executes a proposed action.

What is processed

Only the context, question, candidates and model files you explicitly provide. Inference runs on this device using packaged ONNX Runtime Web code. There are no server uploads, analytics, telemetry, account requirements or remote model downloads.

What is retained

Context and results stay in the open panel's memory. Closing the panel ends that session. If you choose “Keep this model on this device,” model assets and their manifest are stored in local IndexedDB, not Chrome Sync. Remove model clears that stored model. Turning off the option also clears the stored copy.

Permissions

The sole extension permission is sidePanel, used to display Vons beside the current tab. No page, cookie, history, clipboard-read, background network or browsing-content access is requested. Copy JSON writes only the displayed result to your clipboard after you click it. Model file access comes from the folder picker you open.

External links

Research and bundle-guide links open Hugging Face only when clicked. That destination has its own privacy policy. Context, candidates and model contents are not included in those links.

Limits and terms

This is research software. Model scores are not calibrated probabilities of correctness. A proposal does not establish quality, consent or permission to act. The current publication reports negative external evaluation results and unresolved deployment gates. Model weights are not included; review their origin and redistribution terms separately.
